## 🎨 Design System: Artisanal Engineering

- **Warm Ivory Background**: `#F7F5EF`
- **Deep Charcoal Text**: `#252724`
- **Primary Accent**: Forest Green `#245B4A` (Hover `#1B4538`)
- **Secondary Accent**: Muted Terracotta `#C66B4E` (Hover `#B0593D`)
- **Card Surfaces**: Pure White `#FFFFFF` with Warm Grey borders (`#E5E1D8`)
- **Typography**: Inter (Body & Display) & JetBrains Mono (Code/Metadata)
- **Icons**: Material Symbols Outlined & Lucide Icons

## ⚡ Tech Stack & Architecture

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 with custom tokens matching `DESIGN.md`
- **Build Tool**: Vite 8 with Rollup bundling
- **Linting**: Oxlint
